## Mi participación

Definí el problema, las reglas impositivas y los controles que tenía que cumplir. Las fichas distinguen las herramientas en uso de las que siguen en prueba o desarrollo.

## Qué contiene este repositorio

El sitio, las fichas públicas, capturas y casos con datos ficticios. Las demostraciones interactivas ilustran controles y se ejecutan en el navegador. El módulo [ejemplos.mjs](ejemplos.mjs) contiene su lógica genérica. Los ejemplos no ejecutan las herramientas operativas ni usan archivos de contribuyentes.

## Ejecutar el sitio

Servir esta carpeta con un servidor HTTP estático y abrir su dirección en el navegador. GitHub Pages publica la rama main desde la raíz.
